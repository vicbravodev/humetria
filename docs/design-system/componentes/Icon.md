Íconos de trazo para la interfaz, con el mismo lenguaje que Lucide, el set por defecto de shadcn.

En la app no hay un componente `Icon`: se importa de `lucide-react`. Para el ícono propio de cada herramienta usa `ToolIcon` (`components/humetria/tool-icon.tsx`).

Tamaño: 20 px en botones y navegación, 24 px en vistas sueltas.

- Trazo de 1.75 px con remates redondos, como el símbolo de Humetría.
- Siempre acompañados de texto, salvo botones de ícono con `aria-label`.
