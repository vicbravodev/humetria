# NOM-035-STPS-2018 en Humetría

- [`criterios.md`](criterios.md): **cómo aplicamos la norma y por qué**, criterio por criterio, con su fuente. Manda
  sobre cualquier otro documento en cuanto a la interpretación de la NOM-035, y está escrito para poder explicárselo a
  clientes o usarlo en un manual.

- [`fuentes/`](fuentes/README.md): copias de las fuentes oficiales con fecha de descarga y huella.
